# BlogHub ✨

A modern full-stack blogging platform built with Node.js, Express.js, MongoDB, HTML, CSS, and JavaScript.

## Features

- Create Blog Posts
- Read All Posts
- Read Single Post
- Edit Existing Posts
- Delete Posts
- MongoDB Database Integration
- REST API CRUD Operations
- Responsive Mobile Design
- Loading States
- Toast Notifications
- Delete Confirmation Popup
- Professional UI/UX

## Tech Stack

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB

## API Endpoints

GET /posts

GET /posts/:id

POST /posts

PUT /posts/:id

DELETE /posts/:id
